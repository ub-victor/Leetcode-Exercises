# LeetCode Exercises

This repository collects solved algorithm and coding exercises. Each solution is stored as a self-contained folder or file with a short explanation and tests when relevant.

## Structure
- /problems/
    - `LeetCode/` — solution files, README, tests
    - `problem/`
- /templates/ — starter templates (Python, JavaScript, C++, etc.)
- README.md — this file

## Conventions
- Folder names: `Leetcode` or `leetcode-<id>-brief-title`
- Solution filename: `solution.<ext>` (or language-specific name)
- Include a small README in each problem folder describing:
    - problem source (link or id)
    - complexity (time/space)
    - short explanation
    - how to run

## How to run
- Python: `python3 solution.py`
- Node: `node solution.js`
- C++: `g++ solution.cpp -o solution && ./solution`

Include a basic input mechanism or a small test harness in each solution folder.

## Contribution
- Add new problems under `/problems/` following the conventions.
- Keep commits focused and include the problem id/title.
